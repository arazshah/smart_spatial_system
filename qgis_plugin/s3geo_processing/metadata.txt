about=S3Geo adds a chat panel to QGIS: you write what you want in plain language (any language), a model you configure (any OpenAI-compatible endpoint: OpenAI, AvalAI, OpenRouter, Ollama, LM Studio, ...) picks and runs the analysis tools of the s3geo MCP server on your layers, and the results appear as new layers. Layer geometries are never sent to the model. It also adds the Smart Spatial System analysis tools to the QGIS Processing Toolbox. Distances, areas and buffers are computed in metres (the data is reprojected to the matching UTM zone automatically and the result returns in EPSG:4326). A generic algorithm runs any of the 100 capabilities by name, and an optional algorithm answers natural-language questions through an LLM you configure. The plugin needs the Python package smart_spatial_system with the mcp extra (pip install "smart_spatial_system[mcp]") in the Python that QGIS uses; see the plugin homepage for the install steps per operating system.
