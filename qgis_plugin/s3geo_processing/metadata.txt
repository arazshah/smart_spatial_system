about=S3Geo adds the Smart Spatial System analysis tools to the QGIS Processing Toolbox. Distances, areas and buffers are computed in metres (the data is reprojected to the matching UTM zone automatically and the result returns in EPSG:4326). A generic algorithm runs any of the 100 capabilities by name, and an optional algorithm answers natural-language questions through an LLM you configure. The plugin needs the Python package smart_spatial_system (pip install smart_spatial_system) in the Python that QGIS uses; see the plugin homepage for the install steps per operating system.
